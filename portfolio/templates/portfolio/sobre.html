1. Arquitetura MVT do Django

📸 [A tua fotografia do desenho em papel MVT vai aparecer aqui]

O Django utiliza o padrão MVT (Model-View-Template):

  • Model (Modelo): É a camada de acesso aos dados. Define a estrutura da base de dados em código Python.
  • View (Vista): É o "cérebro" ou controlador. Recebe o pedido HTTP, vai aos Models buscar a informação, e envia para o Template.
  • Template: É a camada de apresentação (HTML/CSS). Pega nos dados e renderiza-os no browser.
